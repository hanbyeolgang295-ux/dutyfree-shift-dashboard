# 외국인은 돌아왔는데, 면세점은 왜 텅 비었을까?

한국관광공사 쇼핑관광 마케터를 위한 Streamlit 대시보드 (산업데이터시각화 개인 프로젝트, 강한별)

## 질문
외국인 관광객은 역대 최대인데 면세점 매출은 반토막이 됐다. 외국인 쇼핑의 돈은 어디로 옮겨갔을까?

## 가설과 결과
| | 가설 | 결과 |
|---|---|---|
| H1 | 관광객은 늘었지만 1명당 면세점 지출은 줄었다 | 맞음: 121만 원(2019) → 50만 원(2025). 대부분 "면세점에 안 가서"(1명당 구매 횟수 반토막) |
| H2 | 줄어든 쇼핑은 로드샵·체험·온라인으로 옮겨갔다 | 맞음: 카드 지출 면세점 0.6배, 로드샵 2.1배, 뷰티 3.2배 / 해외 온라인 화장품 판매 7배 |
| H3 | 관광객이 많이 늘어난 나라일수록 귀국 후 온라인 구매도 많이 늘었다 | 기각: 관계 없음(8개 지역). 온라인은 방문과 따로 큰다 |

## 데이터 (모두 공공데이터)
- 관광지식정보시스템 · 목적별/국적별 입국 통계 (법무부 출입국, 월, 2015.01–2026.10)
- 한국면세점협회 · 산업동향 (내/외국인 매출·구매 인원, 연 2009–2025, 월 최근 13개월)
- 국가데이터처 KOSIS · 온라인쇼핑동향조사 「지역별/상품군별 온라인쇼핑 해외직접판매액」 (DT_1KE10081, 분기 2014.1Q–2026.3Q)
- 한국관광데이터랩 · 신용카드 외국인 관광지출액 (업종별, 연 2018–2025)

## 구조
```
app.py                  대시보드
pipeline/preprocess.py  전처리 (raw/ → data/)
pipeline/raw/           원자료 (용량이 큰 입국 xls·KOSIS csv는 위 출처에서 내려받아 넣으면 재현 가능)
data/                   대시보드가 읽는 가공 데이터
```

## 실행
```
pip install -r requirements.txt
python pipeline/preprocess.py   # 원자료가 있을 때만
streamlit run app.py
```

AI 활용: 데이터 수집 보조, 전처리·대시보드 코드 작성에 Claude(Anthropic)를 사용했습니다.
